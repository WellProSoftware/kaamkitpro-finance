# Professional Projection Software

A professional financial projection and project report application.

## Features
- Project cost and funding calculations
- Revenue and expense projections
- Profit and loss analysis
- Cash flow and loan repayment estimates
- DSCR and break-even analysis
- Excel and PDF report exports
- Hospital, pharmacy, optical, retail, warehouse and manufacturing projects

## Development
This project will be built and tested separately before any production website changes.

## Safety
Never commit passwords, API keys or other secrets to this repository.
The existing production website and live payments must remain unchanged during development.
